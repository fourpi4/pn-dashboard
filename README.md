# Подоходный налог · ОФ

Дашборд учёта **подоходного налога (ПН)** по организациям базы **ОФ**
(Маркет Плейс, Сайкал Стор, Галерея Ош, Даана Ош, Бест Аккаунтинг) и регионам
(АУП, Кызыл Кия, Джалал Абад). Сделан по образцу «Кадры и ЗП · ОФ», с тем же
оформлением и теми же правилами расчёта ПН.

- **Итоги** за период по организациям / регионам: начислено, взносы ПФ + ГНПФ,
  стандартные вычеты, облагаемая база, ПН удержан, ПН с МРД, ПН всего, уплачено, остаток.
- **ПН по месяцам** за год: начислено, уплачено, остаток, срок и статус
  («до 20.11 · N дней», «Просрочено», «Оплачено», «Переплата»); клик по месяцу открывает этот период.
  Будущие месяцы показаны как «прогноз» и в итоги не входят.
- **Ведомость ПН** по сотрудникам: начисленное, необлагаемые доходы и «дней факт» правятся прямо в таблице.
- **Платежи**: платёжные поручения по ПН (организация, регион, за какой месяц, дата, №, сумма).
- **Калькулятор ПН**: из начисленного или из суммы на руки, с учётом категории, иждивенцев, необлагаемых и МРД.
- **Excel**: «⬇ Шаблон Excel», «📥 Загрузить из Excel» (добавляет или обновляет сотрудников,
  начисления идут за выбранный период), «Выгрузить в Excel» (ведомость, месяцы, платежи).

**Сайт:** https://fourpi4.github.io/pn-dashboard/ (GitHub Pages, публикуется автоматически при пуше в `main`).

## Связь с ботом «Аванс»
Сайт и бот `fourpi4/avans-osh` обмениваются данными:
- **бот → сайт: авансы** за месяц — кто, сколько, статус (ждёт / одобрен / выдан / отклонён), даты. На главной —
  таблица «Авансы из бота» с организацией и регионом сотрудника; в ведомости — «Аванс (бот)» и «К выплате» = на руки − аванс.
  Сотрудник сайта связывается с ботом по Telegram ID (поле в карточке), затем по ИНН, затем по ФИО.
- **сайт → бот: зарплаты.** «📤 Начисления → бот» — сумма «на руки» за месяц становится заработком сотрудника в боте
  (от неё лимит аванса 70%). Бот сначала показывает проверку; за месяц зарплату можно отправить один раз.
- **данные сайта** (сотрудники, начисления, платежи, ставки) хранятся на сервере бота в зашифрованном виде — одинаково
  на любом компьютере.

Подключение: «🔗 Бот «Аванс»» → адрес бота (`https://avans-osh.onrender.com`) и ключ из команды **/pn_key** в боте
(только у администратора). Ключ запоминается только в этом браузере, в коде сайта его нет. Бесплатный сервер Render
засыпает, поэтому первое подключение может занять до минуты.

## Локальный запуск
- Двойной клик по `app/ui/index.html` не подойдёт для связи с ботом (бот принимает запросы только с сайта и с localhost:8081), поэтому:
- `python -m app.main` → http://localhost:8081 (порт 8081, чтобы не мешать «Кадрам» на 8080), или
- `docker compose up -d --build` → http://localhost:8081.

## Правила расчёта (НК КР 2022)
| Показатель | Правило |
|---|---|
| Начислено | из ведомости за месяц; пусто — оклад |
| Взносы, уменьшающие базу | ПФ 8% + ГНПФ 2% (пенсионер 8% + 0, инвалид I–II 2% + 0) с min(начислено, 720 940) |
| Стандартный вычет | 650 + 100 × иждивенцы (ст. 194) — только ≥ 15 дней в месяце и не совместителю (ст. 200 ч. 7); в карточке можно включить или выключить |
| ПН (гр. 16) | 10% × (начислено − необлагаемые − ПФ − ГНПФ − вычет) |
| ПН с МРД (гр. 17) | МРД = 60% СМЗ района; если база < МРД — (МРД − база) × 10% за счёт работодателя; не для совместителей, МОП, инвалидов; пропорционально «дням факт» |
| Категория «Авто» | пенсионер по ИНН: женщины с 58, мужчины с 63 лет |
| Срок уплаты | до 20-го числа следующего месяца |
| Дней факт | вводится; иначе календарь минус пятницы |

**СМЗ районов** вводятся в «⚙ Ставки и СМЗ районов» (таблица организация × регион). Если СМЗ не введена, МРД не применяется.
